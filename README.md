## Aim

To develop a neural network regression model using a numerical dataset.

## Dataset

The dataset contains house sizes as input features and house prices as target values.

## Technologies Used

* Python
* PyTorch
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Model Architecture

* Input Layer: 1 neuron
* Hidden Layer: 16 neurons with ReLU activation
* Output Layer: 1 neuron

## Training

The model is trained using the Adam optimizer and Mean Squared Error (MSE) loss function.

## Visualization

The training loss versus iterations is plotted to observe the model's learning progress.

## Result

The neural network learns the relationship between house size and house price and predicts house prices for new input values.

## How to Run

1. Install the required libraries.
2. Place the CSV dataset in the working directory.
3. Run `regression_model.ipynb`.
4. Observe the training loss graph and prediction results.
